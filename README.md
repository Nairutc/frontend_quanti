# Frontend Quanti

Aplicación web desarrollada con React para la gestión de la Academia Quanti.

El frontend consume la API REST de Quanti y permite administrar usuarios, profesores, cursos e inscripciones.

## Funcionalidades

- Registro de usuarios.
- Inicio y cierre de sesión.
- Autenticación mediante JWT.
- Rutas protegidas.
- Acceso según el rol del usuario.
- Panel de administración.
- Panel de estudiantes.
- Panel de profesores.
- Gestión de usuarios.
- Gestión de profesores.
- Gestión de cursos.
- Gestión de inscripciones.
- Actualización de datos personales.
- Carga de foto de perfil.
- Validación de formularios.
- Manejo de mensajes de éxito y error.

## Roles

### Administrador

Puede administrar:

- Usuarios.
- Profesores.
- Cursos.
- Inscripciones.

### Profesor

Puede ingresar a su panel y administrar los datos de su perfil.

### Estudiante

Puede ingresar a su panel y administrar los datos de su perfil.
